# DropShop — دليل التشغيل والرفع

نظام محاسبة وإدارة طلبات دروبشيبنغ يعمل كتطبيق مصغّر (Mini App) داخل تيليجرام، فيه واجهة للتاجر وواجهة للإدارة، مع بوت يرسل الإشعارات.

---

## 1) محتويات المشروع

| الملف | وظيفته |
|---|---|
| `server.js` | الخادم وكل عمليات النظام (الطلبات، المخزون، التسويات، الاشتراكات) |
| `db.js` | قاعدة البيانات (SQLite) — تُنشأ تلقائياً عند أول تشغيل |
| `bot.js` | بوت تيليجرام: أوامر `/start` و `/id` وإرسال الإشعارات والملفات |
| `auth.js` | التحقق من أن المستخدم قادم فعلاً من تيليجرام (حماية) |
| `public/` | واجهة التطبيق (index.html + app.js + style.css) |
| `.env.example` | نموذج الإعدادات — تنسخه باسم `.env` |
| `Dockerfile` | للرفع على أي استضافة تدعم Docker |

البيانات كلها (قاعدة البيانات + الصور وملفات الطباعة) تُحفظ داخل مجلد واحد هو `DATA_DIR`. **هذا المجلد هو أهم شيء للنسخ الاحتياطي.**

---

## 2) قبل كل شيء: إنشاء البوت

1. افتح تيليجرام وابحث عن **@BotFather**.
2. أرسل `/newbot` ثم اختر اسماً للبوت ومعرّفاً ينتهي بـ `bot` (مثل `dropshop_iq_bot`).
3. سيعطيك **التوكن** بهذا الشكل: `1234567890:AAH...` — احفظه، ولا تشاركه مع أحد.

> زر فتح التطبيق في البوت يُضبط تلقائياً من الكود، فلا تحتاج إعدادات إضافية في BotFather.
> (اختياري) لو أردت رابطاً مباشراً للتطبيق مثل `t.me/your_bot/app`: في BotFather أرسل `/newapp` واتبع الخطوات مع وضع رابط موقعك.

---

## 3) الإعدادات (ملف `.env`)

انسخ `.env.example` باسم `.env` واملأه:

| المتغير | القيمة |
|---|---|
| `BOT_TOKEN` | التوكن من BotFather |
| `APP_URL` | رابط موقعك بعد الرفع، يجب أن يبدأ بـ `https://` |
| `ADMIN_IDS` | رقم حسابك على تيليجرام (وأرقام باقي المشرفين مفصولة بفاصلة) |
| `ORDERS_CHAT_ID` | اختياري: رقم مجموعة الطباعة (انظر القسم 7) |
| `DATA_DIR` | مكان حفظ البيانات |
| `DEV_MODE` | اتركه `false` على السيرفر الحقيقي |

**كيف أعرف رقم حسابي؟** بعد تشغيل النظام أرسل `/id` للبوت، سيرد برقمك. ضعه في `ADMIN_IDS` ثم أعد تشغيل النظام. (أو استخدم بوت @userinfobot).

---

## 4) الطريقة الأسهل: الرفع على Railway (بدون سيرفر)

مناسبة إذا لم تتعامل مع السيرفرات من قبل. Railway خدمة مدفوعة باشتراك شهري بسيط، وتعطي فترة تجربة.

1. أنشئ حساباً على **github.com** ثم أنشئ مستودعاً جديداً **خاصاً (Private)** وارفع إليه ملفات المشروع (بدون مجلد `node_modules` وبدون ملف `.env`).
   - من الموقع مباشرة: زر **Add file → Upload files** واسحب الملفات والمجلدات.
2. ادخل **railway.com** وسجّل بحساب GitHub.
3. **New Project → Deploy from GitHub repo** واختر المستودع. سيكتشف Railway ملف `Dockerfile` ويبني المشروع تلقائياً.
4. **أضف قرصاً دائماً (مهم جداً، وإلا تضيع البيانات مع كل تحديث):**
   - من صفحة المشروع اضغط بزر الفأرة الأيمن على الخدمة أو من **+ Create → Volume**، واجعل مسار التركيب **Mount path** = `/data`.
5. من تبويب **Variables** أضف:
   ```
   BOT_TOKEN=التوكن
   ADMIN_IDS=رقمك
   DATA_DIR=/data
   DEV_MODE=false
   ```
6. من **Settings → Networking → Generate Domain** سيعطيك رابطاً مثل `https://dropshop-production.up.railway.app`.
7. أضف المتغير `APP_URL` بهذا الرابط. سيعيد Railway التشغيل تلقائياً.
8. افتح البوت في تيليجرام وأرسل `/start` — سيظهر زر **DropShop** بجانب خانة الكتابة.

## 5) الطريقة الاحترافية: سيرفر خاص VPS (Ubuntu)

مناسبة إذا عندك سيرفر (Hetzner أو Contabo أو DigitalOcean أو غيرها) ودومين.

### أ) تجهيز السيرفر
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs nginx build-essential unzip
sudo npm install -g pm2
```

### ب) رفع الملفات
- **من ويندوز:** استخدم برنامج **WinSCP** وارفع ملف الـ zip إلى `/home/ubuntu/` ثم:
```bash
cd /home/ubuntu && unzip dropshop.zip && cd dropshop
```
- أو عبر git إذا رفعته على GitHub: `git clone رابط-المستودع dropshop && cd dropshop`

### ج) التثبيت والتشغيل
```bash
npm install --omit=dev
cp .env.example .env
nano .env          # املأ القيم ثم Ctrl+O للحفظ و Ctrl+X للخروج
pm2 start server.js --name dropshop
pm2 save
pm2 startup        # انسخ الأمر الذي يظهر لك ونفّذه ليعمل النظام تلقائياً بعد إعادة تشغيل السيرفر
```

### د) ربط الدومين وشهادة HTTPS (إلزامية لتيليجرام)
1. من لوحة الدومين أضف سجل **A** يشير إلى IP السيرفر، مثلاً `shop.example.com`.
2. أنشئ ملف إعداد Nginx:
```bash
sudo nano /etc/nginx/sites-available/dropshop
```
والصق فيه (غيّر الدومين):
```nginx
server {
    server_name shop.example.com;
    client_max_body_size 30M;   # ضروري لرفع ملفات الطباعة الكبيرة

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
3. فعّله واحصل على الشهادة المجانية:
```bash
sudo ln -s /etc/nginx/sites-available/dropshop /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d shop.example.com
```
4. ضع `APP_URL=https://shop.example.com` في `.env` ثم `pm2 restart dropshop`.

### أوامر مفيدة
```bash
pm2 logs dropshop      # عرض السجلات والأخطاء
pm2 restart dropshop   # إعادة التشغيل بعد تعديل .env أو الملفات
```

## 6) أول استخدام

1. **الإدارة:** افتح البوت ← زر DropShop ← ستدخل لوحة الإدارة مباشرة (لأن رقمك في `ADMIN_IDS`).
2. اذهب إلى **المخزون**: اضبط الأسعار (التكلفة، سعر البيع للتاجر، التوصيل، رسوم المرتجع) ثم أدخل الكميات لكل لون وقياس. يمكنك إضافة ألوان وقياسات جديدة واختيار درجة كل لون.
3. **التجار:** يفتح التاجر البوت ← يكتب اسم متجره ومعرّف إنستغرام ← يصلك إشعار «طلب اشتراك جديد» ← تفعّله من صفحة **التجار**.
   - أو فعّل التاجر مسبقاً بكتابة معرّف إنستغرام الخاص به، وسيُفعَّل حسابه تلقائياً بمجرد فتحه البوت وتسجيله بنفس المعرّف.
   - **الاشتراك مفتوح بدون مدة**، ويبقى فعّالاً حتى تضغط «إيقاف».

## 7) مجموعة الطباعة (اختياري لكن مفيد جداً)

يرسل البوت كل طلب جديد إلى مجموعة خاصة، مع **صور الموكاب** و**ملفات الطباعة بجودتها الأصلية** كملفات قابلة للتحميل، فيستلمها فريق الطباعة مباشرة.

1. أنشئ مجموعة في تيليجرام وأضف البوت إليها.
2. أرسل `/id` داخل المجموعة، سيرد برقم المحادثة (يبدأ بـ `-100...`).
3. ضعه في `ORDERS_CHAT_ID` وأعد التشغيل.

---

## 8) التجربة على جهازك قبل الرفع (اختياري)

```bash
npm install
cp .env.example .env
```
في `.env` اجعل: `DEV_MODE=true` و `ADMIN_IDS=1000` (التوكن غير ضروري هنا). ثم:
```bash
npm start
```
- واجهة الإدارة: `http://localhost:3000/?as=1000`
- واجهة تاجر تجريبي: `http://localhost:3000/?as=2000`

> ⚠️ لا تفعّل `DEV_MODE=true` على السيرفر الحقيقي أبداً، لأنه يسمح بالدخول بدون تيليجرام.

## 9) النسخ الاحتياطي

انسخ مجلد البيانات بالكامل (`DATA_DIR`) بشكل دوري. على VPS يمكنك إضافة نسخة يومية تلقائية:
```bash
mkdir -p ~/backups
crontab -e
```
وأضف السطر (يحفظ نسخة كل ليلة الساعة 3 ويحذف ما هو أقدم من 14 يوماً):
```
0 3 * * * tar czf ~/backups/dropshop-$(date +\%F).tgz -C /home/ubuntu/dropshop data && find ~/backups -mtime +14 -delete
```

## 10) طريقة الحساب

- **ربح التاجر** للطلب المسلَّم = السعر الكلي − التوصيل − (عدد القطع × سعر البيع للتاجر)
- **ربح الإدارة** = عدد القطع × (سعر البيع للتاجر − التكلفة)
- **المرتجع:** يتحمل التاجر «رسوم المرتجع» فقط، والإدارة تتحمل تكلفة القطع.
- **المخزون:** يُخصم عند «قبول» الطلب، ويُعاد تلقائياً إذا رُفض الطلب قبل خروجه للتوصيل.
- كل طلب يحتفظ بنسخة من الأسعار وقت إنشائه، فتغيير الأسعار لاحقاً لا يغيّر حسابات الطلبات القديمة.
- **المحفظة** في صفحة «حسابي» تعرض للتاجر مجموع أرباح الطلبات المسلّمة والمرتجعة التي لم تتم تسويتها بعد، وأرباح الطلبات قيد التنفيذ، وسجل التسويات.
- **التسوية** من صفحة «المالية»: تحدد الطلبات ← «تسوية المحدد» ← تُقفل هذه الطلبات ويصل للتاجر إشعار بالمبلغ.

## 11) حل المشاكل الشائعة

| المشكلة | الحل |
|---|---|
| تظهر رسالة «افتح التطبيق من داخل بوت تيليجرام» | فتحت الرابط من المتصفح. افتحه من زر البوت. |
| زر DropShop لا يظهر في البوت | تأكد أن `APP_URL` صحيح ويبدأ بـ `https://` ثم أعد التشغيل وأرسل `/start`. |
| أدخل كتاجر وليس كإدارة | رقمك غير موجود في `ADMIN_IDS`، أو لم تُعِد التشغيل بعد التعديل. |
| فشل رفع ملف كبير | زد `client_max_body_size` في إعداد Nginx. الحد الأقصى في النظام 25MB لكل ملف. |
| لا تصل إشعارات البوت للتاجر | يجب أن يكون التاجر قد ضغط `/start` في البوت مرة واحدة على الأقل. |
| ضاعت البيانات بعد التحديث على Railway | لم يتم ربط Volume على `/data` أو `DATA_DIR` غير مضبوط. |
